I study computer science at the Technical University of Munich. My work is on AI agents: how to evaluate them honestly, and how to make the decisions they take calibrated and verifiable.

This page collects my research notes, papers and open-source software. Code is on GitHub.

Software

  • theorem

    A graph query and construction language for AI agents. Every query is verified whole before it runs.

  • nanojev

    Typed, calibrated decisions from a local model, without token generation.

  • toolJev

    Code Mode for MCP where the sub-model is a calibrated decision model rather than an LLM. Benchmarked on MCPToolBench++, LiveMCPBench, When2Call and live Claude agents.

  • graft

    Source control for agent-scale monorepos: server-side changesets, derived data, want-only tiered fetch, lock-free landing.

  • distillery

    An autoresearch-style loop for distilling a large API model into a small one.

  • synapse

    Shared context between coding agents (Claude Code, Codex, Gemini and others) on one canvas.
